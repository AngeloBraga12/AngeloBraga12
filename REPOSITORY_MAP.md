## Regra de organização

Um projeto que aparece no portfólio deve ter:

1. README claro.
2. Stack declarada.
3. Instruções de execução.
4. Screenshot ou demonstração quando fizer sentido.
5. Deploy ou instrução de deploy quando aplicável.
6. `.gitignore` adequado.
7. Nenhum segredo ou credencial versionado.
8. Commits que expliquem o que mudou.
9. Código suficientemente limpo para leitura por recrutadores e outros desenvolvedores.

## Netlify

A versão atualmente publicada do portfólio em `portifolio-angelo.netlify.app` é a referência de produção. A sincronização integral do código-fonte dessa versão com o GitHub deve ocorrer antes de tratar o repositório como fonte definitiva de deploy.

Depois da sincronização, o fluxo recomendado é GitHub como fonte de código e Netlify como plataforma de build/deploy contínuo.
